# SeatBond

影院连座锁座：按场次厅图查找连续空座，过道列断开，冲突检测既有持座。

## 拆排与禁坐规则

- **拆排开关**（锁座页，默认关闭）：单排连续空座不够人数、但多排合计够时，开启后允许把一单拆成多段持座；多段共用同一锁座单号，每段自身连续、不跨过道。关闭时单段不够即失败并写冲突。
- **遮挡禁坐**：影厅可配置 `blocked_seats`（`排:列` 逗号分隔），遮挡格不可占、不可跨，座位图以 ✕ 标出。
- **冻结厅图**：影厅 `frozen` 后整单拒锁并写冲突。
- 任一段撞上遮挡、冻结或其他禁坐规则 → 整单失败回滚，不会留下半成功多段。
- 订单页按单号聚合展示各段起止；座位图同时点亮多段占用。

## 启动

```bash
docker compose up --build
```

| 服务 | 地址 |
| --- | --- |
| 前端 | http://localhost:4100 |
| API | http://localhost:9100 |
| API 文档 | http://localhost:9100/docs |
| Postgres | localhost:5442 |

健康检查：`GET http://localhost:9100/api/health`

## 页面

- `/halls` — 影厅
- `/showtimes` — 场次
- `/seatmap` — 座位图（大网格热力）
- `/hold` — 锁座
- `/orders` — 订单
- `/conflicts` — 冲突

## 使用说明

1. 在影厅与场次页确认厅图与排期。
2. 打开座位图查看占用热力，在锁座页输入连座人数并提交。
3. 订单页查看持座结果；冲突页查看重叠请求。
